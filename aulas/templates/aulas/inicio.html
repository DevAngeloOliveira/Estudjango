O caminho de uma página

URL → View → Template → HTML no navegador

A URL escolhe a view. A view prepara o contexto e chama render(). O template usa esses dados para montar o HTML.

Conheça a sintaxe

Variáveis exibem valores; tags controlam a estrutura da página.
