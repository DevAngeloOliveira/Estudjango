Leia o código desta página

  • for cria uma linha para cada aluno; empty trata a lista vazia.
  • forloop.counter numera as linhas a partir de 1.
  • aluno.nome acessa a chave do dicionário.
  • if / else escolhe a situação de acordo com a nota.
  • floatformat:1 exibe uma casa decimal; length conta os alunos.

Agora é sua vez: edite uma nota na lista em aulas/views.py, atualize a página e observe como a situação muda.
